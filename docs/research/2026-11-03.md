# R012 and R011 stable updates — November 3, 2026

## R012 stable promotion

The owner installed R012 and confirmed stock audio, samples, Recorder and USB
audio work, including after changing projects, then designated R012 stable.
R012 is now the default stable build; R011 is the previous stable release.

R012 removes the private sample-bank build requirement. Only the two official
OS files are needed. Its firmware bytes and hashes are unchanged by this status
update. Long-duration endurance and exact end-to-end USB latency remain
unmeasured. See the [R012 manifest](../../releases/r012.json).

## Earlier R011 stable promotion

R011 became the default stable build following owner-reported success after
installation and loading a different project, with T1E2 retained as the
previous stable target. This published source recipes, checks and documentation;
no firmware, samples or raw hardware captures are distributed.

## Features retained

ONESHOT, WERP, STRETCH, REPITCH, GRID and SLICE remain alongside the stock DN2
synths. R011 includes stereo sample playback, browsing, DT2 parameter graphics,
SLICES trig mode, Recorder with trim/save workflow, and 42-channel class-compliant
USB capture. The stereo USB return is unchanged.

## Project changes and SPI publication

R010 could play the boot project normally, then repeat old audio over USB after
loading another project while headphones remained normal. Sample restoration
had finished. Captures showed continued rendering, a full retained queue and
SPI destination-in-use rejection with no new publications.

The render-time TX selector follows RX completion; it is not a TX ownership
grant. R010 bound the retained FIFO head to a destination derived from that
older phase. R011 instead selects a candidate using the current DMA START.
Existing ownership guards decide whether it can be written.

The native control prefix and trailer, note/release ordering, TDM destination,
FIFO order and native DMA configuration remain unchanged. R011 adds no polling
wait or interrupt hook. MAIN behavior matches R010 except the build identifier.

## Evidence and limits

Native instruction checks reproduce the old stall and verify progress for both
SPI pages and both TDM phases. Invalid ownership snapshots reject without live
writes; unconsumed destinations stay protected and FIFO order survives DMA
turnover. Existing exporter, ABI, queue and post-copy checks pass. Local
preparation also passed both MAIN loader paths, container integrity, exact
SysEx roundtrip and 44 synthetic host tests.

The owner reports successful playback after changing projects and designated
R011 stable. This is not a completed endurance test or a synchronized R011
hardware timing capture. Cross-transport alignment, finite queue capacity and
exact end-to-end USB latency still need measurement. Source reproduction status
and exact hashes are recorded in the [R011 manifest](../../releases/r011.json).

The track-2 sample reload report is resolved: the owner confirmed the project
had not been saved after assignment. No firmware change was required for this
report. Save the project after loading and assigning samples.
