R027 CANDIDATE · SAMPLE STORAGE SETUP

First-time sample storage needs setup.

R027 retains SYSTEM → FORMAT SAMPLES for uninitialized sample storage. The setup and subsequent uploads have been tested on a DN2.

The DN2 already contains the physical flash capacity; stock firmware does not expose this area as sample storage. FORMAT SAMPLES initializes a sample filesystem there. Transfer reported about 20 GB available on the tested DN2.

Formatting erases the sample area, including other mods' data there. Back up first and restart afterward. If sample uploads already work, leave storage intact.

Use FORMAT SAMPLES only. Do not substitute stock FORMAT +DRIVE or reset commands.

NEW IN R027 · SEM FILTER

A SEM-style multimode filter on every track.

SEM joins the stock filters in each track's FILTER selection menu and is available on every Machine, synth or sampler. It follows the Oberheim SEM-style state-variable filter in Faust's vaeffects.lib by Eric Tarr, with soft-clipping integrators. It is a SEM-family model, not a measured copy of a particular instrument.

FREQ, RESO (Q 0.5 to 10), the filter envelope, keytracking, LFOs and parameter locks drive it as on the stock filters. The FILTER page draws SEM's computed response, and the TYPE control shows LP · NOTCH · HP, with the band-pass icon alone at TYPE 127.

The first SEM builds overloaded the DSP and were never published. R025 runs the right effects chain only for sampler voices, which the emulator identifies as the cause; the owner reports R025 working (no timing capture yet) and the R026/R027 displays matching their previews.

USB audio is untested on R027. It was reported broken during that overload and has not been checked since. If you rely on USB audio, stay on R012 until it is confirmed.

Release notes

Install and load your first sample

  1. Back up projects, Sounds and samples; keep an official recovery OS.
  2. Select official DN2 OS 1.11 and DT2 OS 1.16 above. Build and download the verified R027 file.
  3. Install with Elektron Transfer's OS update workflow. Let it finish and boot normally. If the DN2 stays on SUCCESS! REBOOTING, switch it off and on.
  4. If uploads already work, skip formatting. Otherwise, after backing up, stop playback and transfers, close Transfer, then open SETTINGS → SYSTEM → FORMAT SAMPLES. YES erases the sample area, including other mods' data; NO cancels. Never substitute FORMAT +DRIVE.
  5. If you formatted, keep power connected until SAMPLES FORMATTED / SWITCH OFF / ON DN2 appears, then switch off and on. Reconnect Transfer and verify nonzero Samples capacity.
  6. Upload a WAV through Transfer's EXPLORE → Samples view.
  7. From a DN2 track page, press VOICE twice. Browse +DRIVE, select the sample and choose LOAD TO PROJECT.
  8. Choose a sample Machine with FUNC + SYN, assign the sample through SYN → SAMP, then save the project.

During bulk transfers: playback may stutter, miss notes or go quiet. Stop playback before large uploads or restores and wait for completion before playing. After formatting, restore the samples required by existing projects, then reload the project. Report audio problems that continue after transfers finish.
