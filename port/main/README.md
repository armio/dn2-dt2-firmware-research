This source pipeline reconstructs T1E2 MAIN from the ONESHOT/FS baseline produced by `port/dsp/main_baseline.py`. Use the repository's top-level builder for the complete official-input workflow. This lower-level interface accepts extracted DN2 1.11 MAIN, extracted DT2 1.16 MAIN, the rebuilt baseline, rebuilt DSP, filesystem maps and worker symbols.

`build.py` materializes the original recipes under a private workspace, derives donor code/data from the supplied official images, and runs the 115 stages in `stages.json`. Every intermediate MAIN has an expected SHA-256. The final output is `WORK/result/main-os.bin`, SHA-256 `4f2cea43e6a70ae922dc58ac7c02cfb91f72fdeaa4b4146ba72e2007a2c39f96`. This interface neither packages nor transfers firmware. Generated binaries, donor listings and receipts belong only in the private build workspace.

Required arguments: `--work`, `--dn2-main`, `--dt2-main`, `--baseline-dir`, `--maps`, `--worker-symbols`, `--dsp`, `--dnfw-src`, `--digikit`, and `--binutils-prefix`. The binutils prefix identifies the pinned ColdFire tools, for example `/path/to/bin/m68k-linux-gnu-`. `--baseline-dir/main-os.bin` must hash to `205673af2a58674bb239195d4d40a5084d22d626aab59ca11547a31a0d7b0c64`. The maps directory supplies `fn_new_map.txt` and `ram_map.txt`; worker symbols come from the rebuilt v2 storage worker reused by v3. Existing complete stages are verified before reuse. An interrupted stage with no receipt must be removed before retrying.

`tree/` contains original extraction, relocation and assembly recipes, including the early recipes used by the bootstrap pipeline. `metadata/` contains only the address, length, hash and symbol mappings consumed by these recipes. It excludes donor instructions, sample data and captured device memory. `sources.json` records source provenance and adaptations; no firmware, generated object, sample asset or compiled code JSON is included.

Replaying the stable layout requires historical source variants. SampleManager's direct font binding stays in its later fix stage. ManualSliceEditor excludes changes introduced after T1E2, then receives T1E2's separate encoder fix. Two lifecycle assembly variants preserve their original stage order; both contain authored instructions and a zero-initialized registry word. WERP's independent historical DSP build is omitted because the DSP pipeline reconstructs that section separately. The USB descriptor guard reads the descriptor from official DN2 MAIN instead of embedding vendor descriptor bytes.
